================================================================================
 C2FO BICC->ATP  -  OBJECT INSTALL ORDER
================================================================================
 One object per file. Run top-to-bottom. 00_create_user.sql runs FIRST as
 ADMIN/DBA (not listed below - it creates the schema + grants).
 Package SPEC files must run before their BODY file.
 Files marked [ENV] contain per-environment values - review before running.

 Directory layout:
   01_ddl/              CREATE TABLE/VIEW/SEQUENCE/TRIGGER (schema objects)
   02_packages/         package SPEC + BODY files
   03_dml/              INSERT/MERGE seed data (run after the target table)
   04_Anonymous_block/  install-time anonymous PL/SQL blocks (guarded ALTERs)

 Ordering rule: all DDL first, then the anonymous blocks (they ALTER tables
 built in STEP 5 / STEP 4), then the DML seeds (they populate tables built in
 STEPs 2-5), then the packages last.
================================================================================
